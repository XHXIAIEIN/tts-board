# tts-board: local rules

How to propose a change to the look or the sound is in the soul-workstyle skill, `references/interaction.md`.

- The plain-text script editor stays the main place to edit a script. Another editor (cards, a table) can be added
  beside it, but never replaces it as the default
- If the user says that a voice sounds slow, thin or harsh, consider emotion, prosody and the processing chain as
  causes, not only the level or the speed. A level change in a voice variant is 3 dB or less
